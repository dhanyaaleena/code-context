User manual

Code
Context

Know what you're touching.

Put your cursor in a function you didn't write. Code Context tells you what it does in plain language, how people and systems reach it, why it was built, and what breaks if you change it.

This manual covers setup, how to read the panel, a worked example, and what happens when the code changes underneath you.

Who it's for

Engineers new to a codebase, reviewers, and the people around them — product, QA, support — who need to know what a piece of code means without reading it.

What you need

VS Code or Cursor, a Python project in Git. Optional: an AI model for the plain-language layer — via GitHub Copilot, or an Anthropic or Google API key.

Getting started

Set up in three steps

Everything except the plain-language layer works as soon as the extension is installed. No account, no server, nothing leaves your machine until you turn AI on.

01
Install the extension

Command palette → Extensions: Install from VSIX… → choose code-context.vsix. Then Developer: Reload Window.

02
Open a Python project

Open any .py file. The extension indexes the workspace in the background — the status bar shows ⛁ 412 files when it's ready. The first index is saved to disk, so reopening the project later only re-reads the files Git says have changed.

03
Turn on the plain-language layer optional

Open your user settings (Preferences: Open User Settings (JSON)) and add:

"codeContext.ai.enabled": true,
"codeContext.ai.model": "claude-haiku-4-5"

Then give it a way to reach a model — any one of these:

RouteWhat to doWho pays
GitHub Copilot (VS Code) Nothing. If no key is set, the extension uses the editor's own models. Approve the one-time consent prompt. Or set the model to vscode-lm to always use them. Your Copilot plan
Anthropic key Code Context: Set API key → Anthropic → paste a key from console.anthropic.com. Create the key inside a workspace, not at organisation level. API usage
Google key Code Context: Set API key → Google, and pick a gemini-* model. It needs an AIza… key — a project number won't work. API usage
Not usable: Claude Pro/Max or Cursor subscriptions

Neither gives extensions access to its models. Run Code Context: List editor models to see exactly what your editor offers.

Keys are stored safely

In the editor's secret storage — never in settings files or the repository.

It costs very little

A description is well under a cent on Haiku, and each function is paid for once until its code changes.

The one rule to remember

Anything with an amber left border was written by an AI from the evidence. Everything else — steps, routes, callers, commits — was computed directly from your code and Git, and doesn't depend on a model.

What the AI is never allowed to do
Invent

It only sees facts the extension computed. It can't add a route, a feature name or a reason that isn't in them.

Declare code unused

No callers found can mean the analysis missed them, so it never calls anything dead.

Rewrite the step list

Each plain line is tied to a numbered step. It can't merge, drop or reorder them.

Sound surer than it is

Thin evidence means low confidence and a shorter answer. A guess about why is labelled inferred.

The four sections

What each section tells you

What it does

The function's steps in order — read from its body, then put into plain words by the AI. Click a step to jump to that line.

AI · PLAIN LANGUAGE

Needs a login token from the user and access to the user database.

1Checks the login token is genuine
2Finds which user it belongs to
3Refuses the request if there's no user
4Hands back the user's details

● reads   ● writes   ● can fail   ● returns

How it got here

Why the function exists, then the changes since. The commit that first added it is marked ADDED HERE. Click a commit to see its diff.

AI · WHY IT EXISTS

Added so only approved staff could reach the admin tools, once Firebase replaced passwords.

Since tightened to turn away users still waiting for approval.

2026-02-02Reject unapproved users at the door
2025-05-14Add Firebase admin authADDED HERE

Says · inferred when the commits never gave a reason and the AI worked it out from what the code serves.

What it touches

A small map: who calls this above, what it calls below. Click any box to go there — this is how you walk a codebase.

Dashed lines are guesses — the name matched but no import proves the link. Treat them as leads to check.

Detail

The longer version for when you need it: the computed summary, test files that reference the function, the commit the index was built at, and the evidence the AI cited.

Good to know
  • No tests? Detail says so, and the AI raises it as a caution when it matters.
  • Evidence ids like step:2 or commit:827fb4e show exactly which facts a sentence came from.
  • Low confidence means the evidence was thin — the AI is told to say less rather than guess.

Worked example

From a function to an answer

A reviewer opens a pull request that touches compute_ap_signal. They've never seen it. Here's what they put their cursor in — and what they get back.

def compute_ap_signal(ap_payments):
    cutoff = datetime.now(timezone.utc) - timedelta(days=90)
    valid = []

    for p in ap_payments:
        # must have both dates
        due_raw = p.get("due_date")
        pay_raw = p.get("payment_date")
        if not due_raw or not pay_raw:
            continue

        paid = parse_utc(pay_raw)
        # only consider payments made in the last 90 days
        if paid < cutoff:
            continue
        valid.append((paid - parse_utc(due_raw)).days)

    late = [d for d in valid if d > 0]
    return round(len(late) / len(valid), 2) if valid else None
Computed from the code — no AI
1works out cutoff
2goes through each ap_payments
3looks up due raw
4looks up pay raw
5parse utc
6adds to valid
7keeps only the valid where d > 0
8returns round(len(late) / len(valid), 2)…

Real extractor output. Accurate, but in the code's own vocabulary.

With the AI layer — same steps, same order
AI · PLAIN LANGUAGE
1Sets the window to the last 90 days
2Goes through each supplier payment
3Reads when the bill was due
4Reads when it was actually paid
5Turns the payment date into a comparable time
6Records how many days late or early it was
7Keeps only the payments that were late
8Returns the share paid late, e.g. 0.25

Illustrative — the wording varies between runs; the numbering never does.

And at the top of the panel

SUPPLIER PAYMENT SCORING — Works out what share of a supplier's bills were paid late in the last 90 days. If it breaks: payment-risk scores go wrong or blank, and anything that ranks suppliers by them misreads who is reliable.

Living with it

When the code changes

Assume an AI agent is editing your code — Cursor's agent in the editor, or Claude Code writing to disk. Code Context notices. It never re-analyses behind your back.

get_current_user()…/auth/deps.py:42
This function changed since it was analysed.Re-analyse
Admin sign-inhaiku 4 5
Checks the login token on every admin request and loads the signed-in user…
  • You're told, not interrupted. Within about half a second of the function changing, the bar appears and the button turns amber. The old answer stays readable.
  • Only real changes count. Edits elsewhere in the file don't flag it. Undo the change and the bar goes away.
  • You decide when to ask again. Click the bar, the ↻ button, or the function's CodeLens.
  • Why not automatically? Agents write in bursts. Re-analysing each burst would describe half-written code and bill you for it.
What leaves your machine
With AI off (default)

Nothing. Indexing, steps, routes, callers and history all run locally against your files and Git.

With AI on

For the function you open: its first 80 lines, its routes, caller and callee names with file paths, commit messages, and co-changed file names. Sent to the provider you chose — nothing else.

SituationAI call?
Opening a function for the first timeYes — one call, typically well under a cent on Haiku

Troubleshooting

No CodeLens above functions

Reload the window. If it persists, Developer: Show Logs → Extension Host will say why.

“No Anthropic API key”

Run Set API key, or on VS Code install GitHub Copilot and leave the key unset.

400: “not scoped to a workspace”

The key was created at organisation level. Create a new one inside a workspace.

Gemini keeps returning 503

That's Google's capacity, not your setup. It retries once; if it keeps failing, switch to Haiku.

Steps show code words, not plain ones

The AI's answer hasn't arrived or couldn't be matched. Click ↻; unmatched steps fall back to the computed label.

A caller is missing

Calls made dynamically — getattr, dispatch tables — can't be seen by reading names. Nothing is ever labelled unused for this reason.
